## 🚀 Быстрый старт

### 1. Клонирование

```bash
git clone https://github.com/your-username/whatsapp-green-api.git
cd whatsapp-green-api
```

### 2. Запуск

```bash
npm run start
```

Откройте http://localhost:4173/ и войдите с вашими данными.
Если не открывается, посмотрите в консоли, адрес будет отображен.

Также доступен режим разработки

```bash
npm run dev
```

Адрес:
http://localhost:5173/
